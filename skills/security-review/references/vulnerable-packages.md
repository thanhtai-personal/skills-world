# Vulnerable & High-Risk Package Watchlist

This file is a **snapshot-derived lead list, not a current vulnerability database**. Package/CVE/version data ages quickly. Before reporting a dependency as vulnerable, verify it against current authoritative advisory data for the relevant ecosystem.

The upstream snapshot included watchlist examples across npm, Python, Maven, Ruby, Rust, and Go, plus general supply-chain red flags such as abandoned packages, deprecated packages with advisories, typosquatting, suspicious ownership transfers, and unusually broad privileges.

Prefer current tooling/advisories such as ecosystem audit commands, OSV/GitHub Advisory Database, RustSec, Go vulnerability database, Maven/Gradle scanners, or equivalent trusted sources available in the execution environment.
